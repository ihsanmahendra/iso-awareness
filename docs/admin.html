Desain Sertifikat

Atur logo, latar, tanda tangan, warna, dan teks sertifikat. Perubahan tersimpan sebagai draf di browser ini dan baru berlaku untuk peserta setelah file desain diunggah ke repo (lihat langkah di bawah).

Teks

Nama organisasi, kota, dan penanda tangan diatur per modul di data/modul.js.

Pratinjau

Cara memasang desain

  1. Klik Unduh file desain. Anda mendapat file desain-sertifikat.js.
  2. Buka halaman unggah folder docs/data di GitHub.
  3. Seret file tadi ke halaman itu (menimpa file lama), lalu klik Commit changes.
  4. Tunggu 1–2 menit. Sertifikat peserta otomatis memakai desain baru.
